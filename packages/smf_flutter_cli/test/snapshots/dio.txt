## App entry

The app is plain Flutter code that nothing regenerates. Change it by hand, unless a section below says what writes a file.

- `main()` in `lib/main.dart` initializes the binding, awaits `bootstrap()` and calls `runApp()`, in this order. Start-up code goes into `bootstrap()`.
- `bootstrap()` in `lib/bootstrap.dart` runs before the first frame, in four phases: what must come before anything else, then the platform services, then the services of the app, then what needs them. Put a new statement into its phase, and import neither `package:flutter/material.dart` nor `package:flutter/cupertino.dart` there.
- Put code that features share into `lib/core/<concern>/`, one directory for each concern. Put a feature, with its screens and their state, into `lib/features/<feature>/`.
- The root of the app asks the system for the icons of the status bar that suit the theme, around every screen, with `StatusBarIcons` of `lib/core/app/status_bar_icons.dart`: dark icons on a light theme, light ones on a dark theme. A screen without an app bar needs no `AnnotatedRegion` for them. Add one only to a screen whose top has another brightness than the theme, such as a picture behind the status bar.
- The app has the flavors `dev`, `staging` and `prod`. A `flutter` command without `--flavor` builds `dev`, in release mode too, so a build for a store takes `--flavor prod`. Code reads the flavor from `appFlavor` of `package:flutter/services.dart`. The app has one entry: add no `main_<flavor>.dart`.

After a change, run:

```bash
dart format lib test
flutter analyze
flutter test
```

Format only `lib/` and `test/`: `dart format .` also formats what Flutter writes into `build/`. The app as generated is formatted, `flutter analyze` finds no issue in it and `flutter test` passes.

- `App` in `lib/app.dart` is the root widget of the app and creates its one `MaterialApp`. Create no other in `lib/`: every screen is below it.
- The `theme`, `darkTheme`, `themeMode`, `locale` and localizations of the app go into the arguments of that `MaterialApp`.

## REST API

- `appRest` in `lib/core/rest/app_rest.dart` makes the requests of the app: `appRest.get('notes')`, `post`, `put`, `patch`, `delete`, `head`. A path is relative to `REST_BASE_URL` in `.env`, with or without a leading slash, and one that climbs out of it with `..` fails with `rejected`. A full address goes where it says. Call it from the state of a screen or from a repository, never from a widget, and create no other `AppRestClient` in the code of the app.
- `response.decoded(Note.fromJson)` turns the JSON of the body into your type, and a body that it does not take fails with `invalidResponse`. A list of JSON is a `List<dynamic>`, so a function of a list takes that and casts its items inside.
- A call fails only with a `RestFailure`: show a text of the app for its `reason`, and its `developerHint` in debug mode only. `failure.response` has the body of a refusal. While `REST_BASE_URL` is empty, a relative path fails with `notConfigured`, and the app still builds and starts.
- `GET` and `HEAD` repeat by themselves after a broken connection and after 429, 502, 503 and 504, keeping to `Retry-After`. Other methods never do. Never wrap a call in a loop of your own.
- The `timeout` of a call is per attempt, 30 seconds by default, so a `GET` with its repeats may take longer. `RestCancel` ends a call: cancel it where the state of a screen is disposed of.
- A new provider implements `RestTransport` of `lib/core/rest/rest_transport.dart`, and only the files of that implementation import it. The code of the app calls neither `createRestTransport()` nor `appRest.use()`, which is for tests.
- In a test, `RestTestServer` of `test/core/rest/rest_test_server.dart` is a local server, or `appRest.use(transport: …)` scripts the answers. `flutter test` otherwise answers 400 to every request, and inside `testWidgets` a request to that server runs in `tester.runAsync`. A request that is still running when a `testWidgets` body ends fails the test with a pending timer.

With `dio`:

- `DioRestTransport` in `lib/core/rest/dio_rest_transport.dart` implements `RestTransport` on `Dio`. In `lib/`, only that file imports the package: other code makes requests through `appRest`.
- `createDio()` in that file creates the `Dio` of the app, and an interceptor goes there. One that logs leaves out the header `authorization` and the query of the address, and none repeats a request or follows a redirect, which `appRest` does.

It returns a `String?` that is `null` while the value is empty or missing, so handle `null`. Never read `.env` or `.env.example` from code.

## REST API

`appRest` in `lib/core/rest/app_rest.dart` makes the requests of the app:

```dart
final notes = (await appRest.get('notes', query: {'page': '1'})).decoded(
  (List<dynamic> json) => [for (final item in json) Note.fromJson(item as Map<String, dynamic>)],
);
```

A path is relative to the address of the API, with or without a leading slash, and keeps the path of that address. One that climbs out of it with `..` fails with `rejected` before anything is sent, so encode what a user types with `Uri.encodeComponent`. A full address with `http://` or `https://` goes where it says, such as a link to the next page or an upload address.

The address is `REST_BASE_URL` in `.env`, as the section "Values in .env" says. It is no secret, and a change takes a new `flutter run`. While it is empty, a relative path fails with `notConfigured`, whose hint names the key, and the app still builds and starts. Use `https` in a release. On a device, `http://10.0.2.2:8080` is your computer on the Android emulator and `http://127.0.0.1:8080` on the iOS simulator, and a phone reaches it at its address on your network. Each environment has an address of its own: change the value by hand, or have CI write `.env` for its job.

A call fails only with a `RestFailure`. Show a text of the app for its `reason`, and its `developerHint` in debug mode only. `failure.response` has the body of a refusal.

`GET` and `HEAD` repeat twice at most after a connection that broke and after 429, 502, 503 and 504, keeping to a `Retry-After` of up to 30 seconds. Other methods never repeat, since the server may have done what they asked, and their failure has the `retryAfter` that the server named.

The `timeout` of a call is per attempt, 30 seconds by default, so a `GET` with its repeats may take longer. A `RestCancel` ends a call at once: cancel it where the state of a screen is disposed of.

/// Why a call failed.
enum RestFailureReason {
  /// A relative path, and no address to join it to:
  /// `REST_BASE_URL` in `.env` is empty, or is no address of a server.
  notConfigured,

  /// The request did not reach a server, or the connection broke.
  network,

  /// No complete answer within the timeout of the attempt, or no token of the
  /// user within [AppRestClient.tokenWait]. It is never repeated: the user
  /// has waited long enough.
  timeout,

  /// The caller cancelled the call with a [RestCancel].
  cancelled,

  /// A 401, after one refresh of the token where the client added one. It
  /// signs nobody out, since a server may refuse for other reasons: the app
  /// decides what it means.
  unauthorized,

  /// A 403.
  forbidden,

  /// A 404.
  notFound,

  /// A 409.
  conflict,

  /// Any other 4xx, or a relative path that climbs out of the address of the
  /// API, which no server got.
  rejected,

  /// A 429.
  tooManyRequests,

  /// A 5xx.
  server,

  /// A body that [RestResponse.decoded] does not take.
  invalidResponse,

  /// Anything else, such as a redirect of a `POST`.
  unknown,
}

/// The only thing that a call of [AppRestClient] throws.
final class RestFailure implements Exception {
  /// Creates the failure.
  const RestFailure(
    this.reason, {
    this.status,
    this.response,
    this.retryAfter,
    this.developerHint,
  });

  /// Why the call failed, which the app shows in a text of its own.
  final RestFailureReason reason;

  /// The status of the answer, if a server answered.
  final int? status;

  /// The answer of a server that refused, whose body may say why:
  /// `failure.response?.decoded(...)`.
  final RestResponse? response;

  /// The wait that the server named, which the client did not take: the
  /// method does not repeat, the wait is too long, or the repeats are over.
  final Duration? retryAfter;

  /// For the developer, in debug mode only. It never has a token.
  final String? developerHint;

  @override
  String toString() => [
    'RestFailure(${reason.name}',
    if (status != null) ', $status',
    if (developerHint != null) ': $developerHint',
    ')',
  ].join();
}

/// What a server answered: the answer of a call with a status of success or
/// with 304, and the refusal in [RestFailure.response].
final class RestResponse {
  /// Creates the response; a test of the code of the app may too.
  const RestResponse({
    required this.status,
    required this.headers,
    required this.bytes,
  });

  /// The status of the answer.
  final int status;

  /// The headers, each name in lower case. [bytes] are always decoded, so a
  /// reply with a `content-encoding` has neither that header here nor its
  /// `content-length`, which would count the coded body.
  final Map<String, String> headers;

  /// The body, decoded of its `content-encoding`.
  final List<int> bytes;

  /// The body as UTF-8.
  String get text => utf8.decode(bytes, allowMalformed: true);

  /// [parse] applied to the JSON of the body, such as
  /// `response.decoded(Note.fromJson)`.
  ///
  /// A body that is no JSON, a body of another type than [parse] takes, and
  /// any error of [parse] fail with [RestFailureReason.invalidResponse], also
  /// an error of the future of an `async` [parse].
  ///
  /// The JSON of a list is a `List<dynamic>` and that of an object a
  /// `Map<String, dynamic>`, whatever they hold. So a function of a list takes
  /// a `List<dynamic>` and casts its items inside:
  /// `(List<dynamic> json) => [for (final item in json) Note.fromJson(item as Map<String, dynamic>)]`.
  /// One that takes a `List<Map<String, dynamic>>` fails with every body.
  T decoded<T, J>(T Function(J json) parse) {
    try {
      final json = jsonDecode(text);
      if (json is! J) {
        throw RestFailure(
          RestFailureReason.invalidResponse,
          status: status,
          response: this,
          developerHint:
              'The JSON of the body is no $J. A list of JSON is a '
              'List<dynamic> and an object a Map<String, dynamic>, so a typed '
              'list needs a cast: take one of those, and cast inside.',
        );
      }
      final parsed = parse(json);
      if (parsed is Future<Object?>) {
        return parsed.catchError(_notFitting) as T;
      }
      return parsed;
    } on RestFailure {
      rethrow;
    } on Object catch (error, stackTrace) {
      _notFitting(error, stackTrace);
    }
  }

  /// Fails with [RestFailureReason.invalidResponse] for [error]. The hint has
  /// its type and not its text, which may quote the body.
  Never _notFitting(Object error, StackTrace stackTrace) =>
      Error.throwWithStackTrace(
        RestFailure(
          RestFailureReason.invalidResponse,
          status: status,
          response: this,
          developerHint: 'The body does not fit: ${error.runtimeType}.',
        ),
        stackTrace,
      );

  @override
  String toString() => 'RestResponse($status)';
}

/// Ends a call, such as one of a screen that the user left: the call fails
/// with [RestFailureReason.cancelled] at once and its connection closes.
final class RestCancel {
  final List<void Function()> _listeners = [];
  bool _isCancelled = false;

  /// Whether [cancel] was called.
  bool get isCancelled => _isCancelled;

  /// Ends the calls that were given this object.
  void cancel() {
    if (_isCancelled) return;
    _isCancelled = true;
    for (final listener in [..._listeners]) {
      listener();
    }
  }
}

  Future<RestResponse> delete(

  /// Makes the call, and turns any error of another kind into a failure with
  /// the reason [RestFailureReason.unknown]. Its hint has the type of the
  /// error and not its text, which may quote a header.
  Future<RestResponse> _request(
    String method,
    String path, {
    Object? json,
    List<int>? bytes,
    Map<String, String>? query,
    Map<String, String>? headers,
    Duration? timeout,
    RestCancel? cancel,
  }) async {
    try {
      if (json != null && bytes != null) {
        throw const RestFailure(
          RestFailureReason.unknown,
          developerHint: 'A call takes json or bytes, not both.',
        );
      }
      final base = _baseOf(_baseAddress);
      final body = json != null ? utf8.encode(jsonEncode(json)) : bytes;
      return await _Call(
        client: this,
        method: method,
        base: base,
        target: _addressOf(path, query, base),
        headers: {
          for (final MapEntry(:key, :value) in (headers ?? const {}).entries)
            key.toLowerCase(): value,
          if (json != null && _hasNoContentType(headers))
            'content-type': 'application/json',
          // Without it a stack may send the body in chunks, which many upload
          // addresses refuse.
          if (body != null) 'content-length': '${body.length}',
        },
        body: body,
        timeout: timeout ?? this.timeout,
        cancel: cancel,
      ).run();
    } on RestFailure {
      rethrow;
    } on Object catch (error, stackTrace) {
      Error.throwWithStackTrace(
        RestFailure(
          RestFailureReason.unknown,
          developerHint: 'The call ended with a ${error.runtimeType}.',
        ),
        stackTrace,
      );
    }
  }

  bool _hasNoContentType(Map<String, String>? headers) =>
      headers == null ||
      !headers.keys.any((name) => name.toLowerCase() == 'content-type');

  /// The address of [path] with [query]; see [AppRestClient].
  Uri _addressOf(String path, Map<String, String>? query, Uri? base) {
    final Uri address;
    if (_absolute.hasMatch(path)) {
      address = Uri.parse(path);
    } else {
      if (base == null) {
        throw RestFailure(
          RestFailureReason.notConfigured,
          developerHint: _baseProblem(_baseAddress),
        );
      }
      final root = base.toString().replaceFirst(RegExp(r'/+$'), '');
      final relative = path.replaceFirst(RegExp('^/+'), '');
      if (_climbsOut(relative)) {
        throw RestFailure(
          RestFailureReason.rejected,
          developerHint:
              'The path "${relative.split(_queryOrFragment).first}" '
              'climbs out of the address of the API, so nothing was sent. Keep '
              'what a user types out of a path, or encode it with '
              'Uri.encodeComponent.',
        );
      }
      address = Uri.parse(relative.isEmpty ? root : '$root/$relative');
    }
    final added = [
      for (final MapEntry(:key, :value) in (query ?? const {}).entries)
        '${Uri.encodeComponent(key)}=${Uri.encodeComponent(value)}',
    ];
    if (added.isEmpty) return address.removeFragment();
    return address.removeFragment().replace(
      query: [if (address.query.isNotEmpty) address.query, ...added].join('&'),
    );
  }

  /// Whether the [relative] path, joined to the address of the API, climbs out
  /// of the path of that address: `..` that goes above where it started,
  /// written as it is or encoded, with a slash that may be encoded too, since a
  /// server may decode it. So the token of the user goes to no other service
  /// behind one host.
  bool _climbsOut(String relative) {
    final segments = relative
        .split(_queryOrFragment)
        .first
        .replaceAll(_encodedDot, '.')
        .split(_slash);
    var depth = 0;
    for (final segment in segments) {
      if (segment == '..') {
        if (--depth < 0) return true;
      } else if (segment.isNotEmpty && segment != '.') {
        depth++;
      }
    }
    return false;
  }

  /// The address in [value] that paths are relative to, or `null` when it is
  /// none: it has no value, is no address of an `http` or `https` server, or
  /// has a query, a fragment or a user.
  Uri? _baseOf(String? value) {
    final uri = value == null ? null : Uri.tryParse(value);
    if (uri == null ||
        !(uri.isScheme('http') || uri.isScheme('https')) ||
        uri.host.isEmpty ||
        uri.hasQuery ||
        uri.hasFragment ||
        uri.userInfo.isNotEmpty) {
      return null;
    }
    return uri;
  }

  /// What the hint of a relative path says for [value], which [_baseOf] did
  /// not take. It does not quote the value, which may have a user.
  String _baseProblem(String? value) => value == null || value.isEmpty
      ? 'REST_BASE_URL in .env is empty, and the path is relative. Put the '
            'address of your REST API there, such as '
            'https://api.example.com/v1, and start flutter run again. The '
            'section "Values in .env" of the README tells how.'
      : 'REST_BASE_URL in .env is no address of a server: it needs http:// or '
            'https://, a host, and no query, fragment or user.';
}

/// One call of [AppRestClient], over its attempts.
final class _Call {
  _Call({
    required this.client,
    required this.method,
    required this.base,
    required this.target,
    required this.headers,
    required this.body,
    required this.timeout,
    required this.cancel,
  }) : _callerHasAuthorization = headers.containsKey('authorization');

  final AppRestClient client;
  final String method;

  /// The address that paths are relative to, whose origin gets the token.
  final Uri? base;

  /// The address of the next attempt, which a redirect changes.
  Uri target;

  /// The headers that the caller gave, which a redirect to another origin
  /// takes away from.
  final Map<String, String> headers;

  final List<int>? body;
  final Duration timeout;
  final RestCancel? cancel;

  /// A header `authorization` of the caller stays, and the token stays out.
  final bool _callerHasAuthorization;

  /// The user whom the call is made for, once a read of the token told.
  String? _owner;

  /// The token that the last attempt sent, if any.
  String? _sent;

  /// The token of a refresh, for the attempt after it.
  String? _refreshed;

  /// Whether the call has made its one refresh.
  bool _didRefresh = false;

  bool get _isSafe => method == 'GET' || method == 'HEAD';

  /// The attempts of the call; see [AppRestClient].
  Future<RestResponse> run() async {
    var repeats = 0;
    var hops = 0;
    for (;;) {
      final RestReply reply;
      try {
        reply = await _attempt();
      } on RestConnectionFailed catch (failure) {
        if (!_isSafe || repeats == _maxRepeats) {
          throw RestFailure(
            RestFailureReason.network,
            developerHint: failure.hint,
          );
        }
        await _wait(_repeatWait(repeats++));
        continue;
      }

      final status = reply.status;
      final response = RestResponse(
        status: status,
        headers: _ofDecodedBody(reply.headers),
        bytes: reply.bytes,
      );
      if (status == 401 && _sent != null && !_didRefresh) {
        await _refresh(_sent!, response);
        continue;
      }
      if (_redirects.contains(status)) {
        _follow(response, hops++);
        continue;
      }
      if (status == 304 || (status >= 200 && status < 300)) return response;

      final retryAfter = _retryAfterOf(reply.headers);
      if (_isSafe &&
          _repeatedStatuses.contains(status) &&
          repeats < _maxRepeats &&
          (retryAfter == null || retryAfter <= _maxWait)) {
        await _wait(retryAfter ?? _repeatWait(repeats));
        repeats++;
        continue;
      }
      throw RestFailure(
        _reasonOf(status),
        status: status,
        response: response,
        retryAfter: retryAfter,
        developerHint: _reasonOf(status) == RestFailureReason.unknown
            ? 'The server answered with the status $status.'
            : null,
      );
    }
  }

  /// One attempt: the token of the user where it may go, and one exchange,
  /// within the timeout. A debug build prints one line for it.
  Future<RestReply> _attempt() async {
    final limit = _Limit(timeout, cancel);
    final watch = Stopwatch()..start();
    var outcome = RestFailureReason.unknown.name;
    try {
      final sent = await _tokenFor(limit);
      _sent = sent;
      final exchange = RestExchange(
        method: method,
        uri: target,
        headers: {
          ...headers,
          if (sent != null) 'authorization': 'Bearer $sent',
        },
        body: body,
        stop: limit.stop,
      );
      final reply = await limit.race(() => client._transport.send(exchange));
      outcome = '${reply.status}';
      return reply;
    } on RestConnectionFailed {
      outcome = RestFailureReason.network.name;
      rethrow;
    } on RestFailure catch (failure) {
      outcome = failure.reason.name;
      rethrow;
    } finally {
      limit.close();
      if (kDebugMode) {
        // The origin and the path alone: the query may have a key.
        debugPrint(
          'REST $method ${target.origin}${target.path} $outcome '
          '(${watch.elapsedMilliseconds} ms)',
        );
      }
    }
  }

  /// [headers] without what no longer holds of a body that the provider decoded;
  /// see [RestResponse.headers].
  static Map<String, String> _ofDecodedBody(Map<String, String> headers) {
    if (!headers.containsKey('content-encoding')) return headers;
    return {...headers}
      ..remove('content-encoding')
      ..remove('content-length');
  }

  /// The token for the next attempt, or `null` for none: an attempt to
  /// another origin gets none, and neither does a call with a header
  /// `authorization` of its own.
  Future<String?> _tokenFor(_Limit limit) async {
    final tokens = client._tokens;
    final origin = base?.origin;
    if (tokens == null ||
        _callerHasAuthorization ||
        origin == null ||
        target.origin != origin) {
      return null;
    }
    if (_refreshed case final refreshed?) {
      _refreshed = null;
      return refreshed;
    }
    final (owner, token) = await limit.race(
      () => _tokenOfOwner(tokens),
      within: client.tokenWait,
    );
    final before = _owner;
    if (before != null && owner != before) throw _otherUser();
    _owner = owner;
    return token;
  }

  /// The user of [tokens] and that user's token. When the user changes during
  /// the read, as when the app starts, the token may be of the user before, so
  /// it reads once more, and fails when the user changes again.
  Future<(String?, String?)> _tokenOfOwner(RestTokens tokens) async {
    final owner = tokens.owner;
    final token = await tokens.current();
    if (tokens.owner == owner) return (owner, token);
    final next = tokens.owner;
    final again = await tokens.current();
    if (tokens.owner != next) throw _otherUser();
    return (next, again);
  }

  /// Gets the token that replaces [rejected], once in a call, for the same
  /// user. The server that refused it did nothing yet, so every method
  /// repeats after it.
  Future<void> _refresh(String rejected, RestResponse response) async {
    _didRefresh = true;
    final tokens = client._tokens!;
    final limit = _Limit(timeout, cancel);
    try {
      final token = await limit.race(
        () => tokens.after(rejected),
        within: client.tokenWait,
      );
      if (token == null || tokens.owner != _owner) {
        throw _otherUser(response: response);
      }
      _refreshed = token;
    } finally {
      limit.close();
    }
  }

  RestFailure _otherUser({RestResponse? response}) => RestFailure(
    RestFailureReason.unauthorized,
    status: response?.status,
    response: response,
    developerHint:
        'The user of the session changed during the call, so '
        'it did not repeat for the new user.',
  );

  /// Goes on to the address that the redirect in [response] names: for `GET`
  /// and `HEAD` only, since the server may have done what another method
  /// asked. A hop to another origin takes the headers of the caller that are
  /// only for the origin they were given for.
  void _follow(RestResponse response, int hops) {
    RestFailure refused(String hint) => RestFailure(
      RestFailureReason.unknown,
      status: response.status,
      response: response,
      developerHint: hint,
    );
    if (!_isSafe) {
      throw refused(
        'The server answered a $method with a redirect, which only GET and '
        'HEAD follow. Call the address that it names yourself, if you mean to.',
      );
    }
    if (hops == _maxRedirects) {
      throw refused('More than $_maxRedirects redirects.');
    }
    final location = response.headers['location'];
    if (location == null) throw refused('A redirect without a location.');
    final next = target.resolve(location).removeFragment();
    if (!(next.isScheme('http') || next.isScheme('https'))) {
      throw refused('A redirect to an address that is no http or https one.');
    }
    if (next.origin != target.origin) _originHeaders.forEach(headers.remove);
    target = next;
  }

  /// Waits for [duration], which a cancel ends at once.
  Future<void> _wait(Duration duration) async {
    final limit = _Limit(null, cancel);
    final waited = Completer<void>();
    final timer = Timer(duration, waited.complete);
    try {
      await limit.race(() => waited.future);
    } finally {
      timer.cancel();
      limit.close();
    }
  }

  static Duration _repeatWait(int repeats) =>
      _repeatWaits[repeats] +
      Duration(milliseconds: _random.nextInt(_maxJitterMilliseconds));

  /// The wait that [headers] name, in seconds or as an HTTP date, or `null`
  /// without one that the client can read.
  static Duration? _retryAfterOf(Map<String, String> headers) {
    final value = headers['retry-after']?.trim();
    if (value == null) return null;
    if (_retryAfterSeconds.hasMatch(value)) {
      final seconds = int.tryParse(value) ?? _maxRetryAfterSeconds;
      return Duration(seconds: min(seconds, _maxRetryAfterSeconds));
    }
    final match = _httpDate.firstMatch(value);
    final month = match == null ? -1 : _months.indexOf(match[2]!);
    if (match == null || month < 0) return null;
    final wait = DateTime.utc(
      int.parse(match[3]!),
      month + 1,
      int.parse(match[1]!),
      int.parse(match[4]!),
      int.parse(match[5]!),
      int.parse(match[6]!),
    ).difference(DateTime.now());
    return wait.isNegative ? Duration.zero : wait;
  }

  static RestFailureReason _reasonOf(int status) => switch (status) {
    401 => RestFailureReason.unauthorized,
    403 => RestFailureReason.forbidden,
    404 => RestFailureReason.notFound,
    409 => RestFailureReason.conflict,
    429 => RestFailureReason.tooManyRequests,
    >= 400 && < 500 => RestFailureReason.rejected,
    >= 500 && < 600 => RestFailureReason.server,
    _ => RestFailureReason.unknown,
  };
}

/// What ends an attempt or a wait: its timeout, if it has one, and the cancel
/// of the caller. The call ends then, also when a provider does not stop.
final class _Limit {
  _Limit(Duration? timeout, this._cancel) {
    final cancel = _cancel;
    if (cancel != null) {
      if (cancel.isCancelled) {
        _cancelled();
      } else {
        cancel._listeners.add(_cancelled);
      }
    }
    if (timeout != null) {
      _timer = Timer(
        timeout,
        () => _end(
          RestFailure(
            RestFailureReason.timeout,
            developerHint:
                'No complete answer within ${timeout.inMilliseconds} ms.',
          ),
        ),
      );
    }
  }

  final RestCancel? _cancel;
  final Completer<void> _stop = Completer();
  Timer? _timer;
  RestFailure? _ended;
  void Function(RestFailure failure)? _racing;

  /// Completes when the attempt has to stop.
  Future<void> get stop => _stop.future;

  void _cancelled() => _end(const RestFailure(RestFailureReason.cancelled));

  void _end(RestFailure failure) {
    if (_ended != null) return;
    _ended = failure;
    _stop.complete();
    _racing?.call(failure);
  }

  /// What [work] gives, unless the limit ends first or [within] is over.
  /// Whatever [work] does after that goes nowhere.
  Future<T> race<T>(Future<T> Function() work, {Duration? within}) async {
    if (_ended case final failure?) throw failure;
    final result = Completer<T>();
    void end(RestFailure failure) {
      if (!result.isCompleted) result.completeError(failure);
    }

    _racing = end;
    final wait = within == null
        ? null
        : Timer(
            within,
            () => end(
              RestFailure(
                RestFailureReason.timeout,
                developerHint:
                    'The token of the user did not come within '
                    '${within.inMilliseconds} ms.',
              ),
            ),
          );
    unawaited(
      Future<T>.sync(work).then(
        (value) {
          if (!result.isCompleted) result.complete(value);
        },
        onError: (Object error, StackTrace stackTrace) {
          if (!result.isCompleted) result.completeError(error, stackTrace);
        },
      ),
    );
    try {
      return await result.future;
    } finally {
      wait?.cancel();
      _racing = null;
    }
  }

  /// Ends the timer of the limit, once what it limits is over.
  void close() {
    _timer?.cancel();
    _cancel?._listeners.remove(_cancelled);
  }
}

/// One exchange of `appRest` on a [Dio], which keeps its connections open
/// between two exchanges, so that a request needs no new TLS handshake.
final class DioRestTransport implements RestTransport {
  /// Creates the transport over what [createDio] creates.
  DioRestTransport(this._createDio);

  final Dio Function() _createDio;
  Dio? _dio;
  HttpOverrides? _overrides;

  /// The [Dio] for the [HttpOverrides] of now. A [Dio] keeps the `HttpClient`
  /// that it created under the overrides of that time, so a change of them, such
  /// as what `RestTestServer` does in a test, takes a new one. In an app that
  /// sets none, this is one [Dio] for as long as the app runs.
  Dio get _current {
    final overrides = HttpOverrides.current;
    final dio = _dio;
    if (dio != null && identical(overrides, _overrides)) return dio;
    // An exchange that is on its way ends as it would have.
    dio?.close();
    _overrides = overrides;
    return _dio = _createDio();
  }

  @override
  Future<RestReply> send(RestExchange exchange) async {
    final cancel = CancelToken();
    unawaited(exchange.stop.then((_) => cancel.cancel()));
    final body = exchange.body;
    try {
      final response = await _current.requestUri<List<int>>(
        exchange.uri,
        // Dio writes any other list as the text of its JSON.
        data: body == null ? null : Uint8List.fromList(body),
        cancelToken: cancel,
        options: Options(
          method: exchange.method,
          headers: exchange.headers,
          followRedirects: false,
          validateStatus: (_) => true,
          responseType: ResponseType.bytes,
        ),
      );
      return RestReply(
        status: response.statusCode!,
        headers: {
          for (final MapEntry(:key, :value) in response.headers.map.entries)
            key.toLowerCase(): value.join(', '),
        },
        bytes: response.data ?? const [],
      );
    } on DioException catch (error, stackTrace) {
      final cause = error.error;
      if (_isOfTheConnection(error)) {
        // The text of an error may quote the address with its query, so the
        // hint has the type alone.
        throw RestConnectionFailed(
          'The connection failed with a ${cause?.runtimeType ?? error.type.name}.',
        );
      }
      // Such as what an interceptor threw. It reaches the caller by its type.
      Error.throwWithStackTrace(cause ?? error, stackTrace);
    }
  }

  /// Whether [error] tells of a connection that failed or broke: on `dart:io`,
  /// a failed TLS handshake and a connection that breaks in a body come as
  /// [DioExceptionType.unknown], with what `dart:io` threw.
  static bool _isOfTheConnection(DioException error) => switch (error.type) {
    DioExceptionType.connectionError ||
    DioExceptionType.connectionTimeout ||
    DioExceptionType.sendTimeout ||
    DioExceptionType.receiveTimeout ||
    DioExceptionType.badCertificate => true,
    DioExceptionType.unknown => error.error is IOException,
    // Not the types by name: a later release of dio may add one, which must
    // not stop an app from compiling.
    _ => false,
  };
}

/// One exchange with a server, as the provider of the REST role sends it.
final class RestExchange {
  /// Creates the exchange; only the client of the app does.
  const RestExchange({
    required this.method,
    required this.uri,
    required this.headers,
    required this.stop,
    this.body,
  });

  /// The method, in upper case.
  final String method;

  /// The whole address, with its query.
  final Uri uri;

  /// The headers, each name in lower case, with `content-length` for a body.
  /// They may hold a token.
  final Map<String, String> headers;

  /// The body, or `null` for none.
  final List<int>? body;

  /// Completes when the exchange has to stop: a timeout, or a cancel.
  final Future<void> stop;

  /// Names no header and no query, so that a token never reaches a log.
  @override
  String toString() => 'RestExchange($method ${uri.origin}${uri.path})';
}

/// What a server answered.
final class RestReply {
  /// Creates the reply; a provider does, from what the server answered.
  const RestReply({
    required this.status,
    required this.headers,
    required this.bytes,
  });

  /// The status of the answer.
  final int status;

  /// The headers, each name in lower case, and several values of one header
  /// joined by `, `.
  final Map<String, String> headers;

  /// The body, decoded of its `content-encoding`.
  final List<int> bytes;
}

/// The request did not reach a server, or the connection broke. No other
/// exception of a provider tells that.
final class RestConnectionFailed implements Exception {
  /// Creates the failure with [hint], for the developer of the app.
  const RestConnectionFailed(this.hint);

  /// What went wrong. It has no header, no query and no body.
  final String hint;

  @override
  String toString() => 'RestConnectionFailed: $hint';
}

/// One exchange on the wire, which is all that a provider of the REST role
/// does. `appRest` does the rest with what the provider reports, so every
/// provider keeps the same guarantees.
///
/// Every provider keeps to this. Only a running app shows whether it does:
/// - [send] makes one attempt. A provider repeats nothing.
/// - It follows no redirect: a 3xx is a reply. `appRest` follows them, since
///   it knows which header may go where.
/// - Any status is a reply, and it keeps the headers of the reply, with their
///   names in lower case. [RestReply.bytes] are decoded of `content-encoding`,
///   so a stack that asks for gzip decodes what it gets.
/// - A failure to connect, a TLS handshake or a certificate that fails, and a
///   connection that breaks are [RestConnectionFailed]. On `dart:io` those are
///   `SocketException`, `HttpException` and `TlsException`. Any other error is
///   a bug of the provider, which reaches the caller as the reason `unknown`.
/// - When [RestExchange.stop] completes, it closes the connection at once. It
///   needs no timeout of its own: `appRest` stops every exchange. On `dart:io`,
///   only a TLS handshake that is on its way stays until the server ends it,
///   since `HttpClient` has no way to end one.
/// - On `dart:io`, one that keeps an `HttpClient` makes a new one when
///   `HttpOverrides` change, as they do when a test starts or closes a
///   `RestTestServer`.
/// - It sends [RestExchange.uri] as it is, with those headers and that body.
///   Its stack may add the headers of the transport itself, such as `host`,
///   `user-agent` and `accept-encoding`. It adds no credential or cookie, and
///   keeps none between two calls.
/// - It writes no header, no query and no body to a log or a hint.

abstract interface class RestTransport {
  /// Sends [exchange] and completes with what the server answered.
  Future<RestReply> send(RestExchange exchange);
}

import 'dart:convert';
import 'dart:io';

import 'package:flutter_test/flutter_test.dart';

/// A request that a [RestTestServer] got.
final class RestTestRequest {
  /// Creates the note of a request.
  const RestTestRequest({
    required this.method,
    required this.uri,
    required this.headers,
    required this.bytes,
  });

  /// The method.
  final String method;

  /// The path and the query.
  final Uri uri;

  /// The headers, each name in lower case.
  final Map<String, String> headers;

  /// The body.
  final List<int> bytes;

  /// The body as UTF-8.
  String get body => utf8.decode(bytes);
}

/// A local server for the tests of the app, for code that makes requests
/// through `appRest`.
///
/// `flutter test` has two traps for a request, and this server is the answer
/// to the first:
/// - The binding of the tests gives every `HttpClient` a stand-in that answers
///   400 to everything, which would reach the code as the reason `rejected`.
///   [start] takes the stand-in away, and the [close] of the last server that
///   is open puts it back.
/// - Inside `testWidgets`, the time is fake, and a real socket never completes
///   there. Make the request in `tester.runAsync`, and let it end before the
///   test does, since the timer of a request that is still running fails the
///   test. A plain `test()` runs in real time and needs nothing.
///
/// Files of tests run at once, so a server takes a free port: give the client
/// [address].
final class RestTestServer {
  RestTestServer._(this._server) {
    _server.listen(_serve, onError: errors.add);
  }

  /// Starts a server on a free port of this machine.
  static Future<RestTestServer> start() async {
    TestWidgetsFlutterBinding.ensureInitialized();
    final server = await HttpServer.bind(InternetAddress.loopbackIPv4, 0);
    if (_open++ == 0) {
      _overrides = HttpOverrides.current;
      HttpOverrides.global = null;
    }
    return RestTestServer._(server);
  }

  /// How many servers are open: the stand-in comes back with the last close.
  static int _open = 0;

  /// What [start] took away.
  static HttpOverrides? _overrides;

  final HttpServer _server;
  bool _closed = false;
  final Map<String, Future<void> Function(HttpRequest request)> _answers = {};

  /// The requests that the server got in full, in order.
  final List<RestTestRequest> requests = [];

  /// What went wrong with a request, such as a client that left during its
  /// upload, which is what a cancel does.
  final List<Object> errors = [];

  /// The address of the server.
  String get address => 'http://${_server.address.address}:${_server.port}';

  /// Answers a request of [method] for [path] with [handler], which closes the
  /// response. Any other request gets a 404.
  void answer(
    String method,
    String path,
    Future<void> Function(HttpRequest request) handler,
  ) => _answers['$method $path'] = handler;

  /// Answers a request of [method] for [path] with [value] as JSON.
  void answerJson(
    String method,
    String path,
    Object? value, {
    int status = 200,
  }) => answer(method, path, (request) async {
    request.response
      ..statusCode = status
      ..headers.contentType = ContentType.json
      ..write(jsonEncode(value));
    await request.response.close();
  });

  /// Stops the server. The last server that is open puts back what [start]
  /// took away.
  Future<void> close() async {
    if (_closed) return;
    _closed = true;
    await _server.close(force: true);
    if (--_open == 0) HttpOverrides.global = _overrides;
  }

  Future<void> _serve(HttpRequest request) async {
    try {
      await _answer(request);
    } on IOException catch (error) {
      errors.add(error);
    }
  }

  Future<void> _answer(HttpRequest request) async {
    final bytes = await request.fold<List<int>>(
      [],
      (all, part) => all..addAll(part),
    );
    final headers = <String, String>{};
    request.headers.forEach(
      (name, values) => headers[name] = values.join(', '),
    );
    requests.add(
      RestTestRequest(
        method: request.method,
        uri: request.uri,
        headers: headers,
        bytes: bytes,
      ),
    );
    final answer = _answers['${request.method} ${request.uri.path}'];
    if (answer != null) return answer(request);
    request.response.statusCode = HttpStatus.notFound;
    await request.response.close();
  }
}
